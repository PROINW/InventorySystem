[ลิ้งค์เข้าสู่ระบบ](http://localhost/InventorySystem) 

**USERNAME : admin**
**PASSWORD : admin**

โปรเจ็กต์นี้คือระบบจัดการคลังสินค้าที่ออกแบบมาเพื่อช่วยในการจัดการสินค้า การขาย หมวดหมู่ และผู้ใช้ในคลังสินค้า มีอินเทอร์เฟซที่ใช้งานง่ายสำหรับผู้ดูแลระบบและผู้ใช้งานทั่วไป

## คุณสมบัติหลัก

- **การยืนยันตัวตนผู้ใช้**: ระบบล็อกอินที่ปลอดภัยสำหรับผู้ใช้และผู้ดูแลระบบ
- **การจัดการสินค้า**: เพิ่ม แก้ไข ลบสินค้าในคลัง
- **การจัดการหมวดหมู่**: จัดระเบียบสินค้าเป็นหมวดหมู่ รวมถึงฟังก์ชันการลบหมวดหมู่
- **การติดตามยอดขาย**: บันทึกยอดขาย ดูยอดขายรายวัน รายเดือน และจัดทำรายงานการขาย
- **การจัดการผู้ใช้**: ฟังก์ชันสำหรับเพิ่ม แก้ไข และจัดการผู้ใช้โดยผู้ดูแลระบบ
- **ข้อมูลบริษัท**: จัดการข้อมูลเกี่ยวกับบริษัทและลบโปรไฟล์บริษัทตามความจำเป็น
- **การเสนอราคาและใบแจ้งหนี้**: สร้าง บันทึก และดูใบเสนอราคาและใบแจ้งหนี้
- **คำสั่งการผลิต**: ยืนยัน เริ่มต้น และจัดการคำสั่งการผลิต
- **ประวัติคำสั่งซื้อ**: ติดตามและตรวจสอบประวัติคำสั่งซื้อ
- **การจัดการโปรไฟล์**: ให้ผู้ใช้จัดการโปรไฟล์และเปลี่ยนรหัสผ่าน

## โครงสร้างไฟล์

### ฟังก์ชันหลัก

- `add_group.php`: เพิ่มกลุ่มสินค้าหรือหมวดหมู่
- `add_product.php`: เพิ่มสินค้าใหม่ในคลัง
- `add_sale.php`: บันทึกการขาย
- `add_user.php`: เพิ่มผู้ใช้ใหม่ในระบบ
- `admin.php`: แดชบอร์ดหลักสำหรับผู้ดูแลระบบในการจัดการระบบคลังสินค้าทั้งหมด

### การยืนยันตัวตนและการจัดการผู้ใช้

- `auth.php` และ `auth_v2.php`: สคริปต์ยืนยันตัวตนผู้ใช้ขั้นพื้นฐานและขั้นสูง
- `login_v2.php` และ `logout.php`: จัดการกระบวนการล็อกอินและออกจากระบบ
- `profile.php`: ให้ผู้ใช้ดูและแก้ไขข้อมูลโปรไฟล์
- `change_password.php`: ให้ผู้ใช้เปลี่ยนรหัสผ่าน
- `users.php`: จัดการรายชื่อผู้ใช้ในระบบ รวมถึงการดูและจัดการผู้ใช้

### ยอดขายและรายงาน

- `sales.php`: จัดการและบันทึกยอดขายในระบบ
- `sale_detail.php`: แสดงรายละเอียดของยอดขายแต่ละรายการ
- `sales_report.php`: จัดทำรายงานยอดขายเพื่อการวิเคราะห์
- `monthly_sales.php`: แสดงยอดขายรายเดือนเพื่อการติดตามผล
- `daily_sales.php`: แสดงบันทึกยอดขายรายวัน

### การจัดการใบเสนอราคาและใบแจ้งหนี้

- `quotes.php`: จัดการใบเสนอราคาสำหรับสินค้าและบริการ
- `view_quote.php`: ให้ดูใบเสนอราคาที่บันทึกไว้
- `save_quote.php`: บันทึกใบเสนอราคาใหม่ในระบบ
- `receipt_invoice.php`: สร้างใบเสร็จและใบแจ้งหนี้สำหรับการขายที่เสร็จสมบูรณ์
- `save_invoice.php`: บันทึกข้อมูลใบแจ้งหนี้เพื่อใช้อ้างอิงในอนาคต

### การจัดการคำสั่งผลิตและคำสั่งซื้อ

- `production_orders.php`: แสดงและจัดการคำสั่งผลิตในระบบ
- `start_production.php`: เริ่มต้นคำสั่งการผลิตใหม่
- `confirm_production.php`: ยืนยันรายละเอียดการผลิตเพื่อประสานงานการติดตามคลังสินค้า
- `edit_production_order.php`: ให้แก้ไขรายละเอียดคำสั่งผลิต
- `production_orders_by_quote.php`: จัดการคำสั่งผลิตตามใบเสนอราคาที่ระบุ
- `order_history.php`: แสดงประวัติคำสั่งซื้อที่ทำในระบบ

### การจัดการบริษัทและสื่อ

- `company.php`: จัดการข้อมูลเกี่ยวกับบริษัทในคลังสินค้า
- `media.php`: จัดการไฟล์สื่อที่เกี่ยวข้องกับสินค้าและหมวดหมู่

### การจัดการหมวดหมู่ กลุ่ม และสินค้า

- `categorie.php`: จัดการหมวดหมู่สินค้า
- `group.php`: จัดการกลุ่มสินค้าในคลัง
- `product.php`: แสดงรายละเอียดสินค้าและจัดการสินค้า
- `edit_categorie.php`, `edit_group.php`, `edit_product.php`: แก้ไขข้อมูลหมวดหมู่ กลุ่ม และสินค้า
- `delete_categorie.php`, `delete_group.php`, `delete_product.php`: ลบหมวดหมู่ กลุ่ม หรือสินค้าตามที่กำหนด

### ฟังก์ชันการลบ

- `delete_company.php`: ลบโปรไฟล์บริษัทจากฐานข้อมูล
- `delete_media.php`: ลบไฟล์สื่อที่เกี่ยวข้องกับสินค้าและหมวดหมู่
- `delete_quote.php`: ลบใบเสนอราคาจากระบบ
- `delete_sale.php`: ให้ผู้ดูแลระบบลบบันทึกการขาย
- `delete_user.php`: ให้ผู้ดูแลระบบลบบัญชีผู้ใช้
